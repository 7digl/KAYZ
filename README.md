# KAYZ — كايز للتوصيل السريع

مشروع Android بسيط يعرض واجهة الطلبات عبر WebView ويرتبط بمشروع Firebase المحدد في `index.html`.

## بناء APK
1. ارفع محتويات هذا المشروع إلى مستودع GitHub في الجذر.
2. افتح تبويب Actions.
3. اختر Build KAYZ APK ثم Run workflow، أو انتظر بناءه بعد رفع الملفات.
4. افتح عملية البناء الناجحة ونزّل artifact باسم KAYZ-debug-apk.
5. فك ضغط artifact لتحصل على `app-debug.apk`.

## تنبيه
هذه نسخة أولية للاختبار. يجب مراجعة قواعد Firestore والتحقق من الأسعار والطلبات من جهة موثوقة قبل النشر التجاري. لا تشارك كلمات المرور أو مفاتيح حساباتك.
